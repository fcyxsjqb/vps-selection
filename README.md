## 一、租 VPS 前，先盯住这五件事

### 1. 线路，而不是“机房在哪儿”

“香港 VPS”这个说法本身没有信息量。香港有机房走软银线路的，也有走三网直连的；美国有机场走国际大带宽 AS4837 的，也有走移动 CMI + 联通 AS9929 双线优化的。同一台配置，线路不同，晚高峰的表现可以差出一倍。

判断方法很土但有效：看官方页面写的回程线路是什么，别只看下行带宽数字。做面向大陆用户的网站，双线优化或三网直连比“1000M 大带宽”实用。

### 2. 带宽和流量，是两件事

- **不限流量型**：带宽小一点，但一个月随便跑，适合博客、面板、常驻服务。
- **流量叠加型**：带宽大，但每月有流量包，用完限速。雨云这类产品的处理方式是每月剩余流量可以叠加到下个月，超出后限速到 1~5Mbps，还能买流量包恢复。

这里有个容易忽略的点：**部分产品的流量是双向计费的**，上行下行都算。买之前确认计费方式，否则跑个下载站，流量费能超过机器本身。

### 3. 防御要不要，取决于你在干什么

普通建站用不上高防。但如果你开游戏服、做社区、或者之前被同行打过一次，那 100G 级的高防就是刚需——而且高防节点通常跟普通节点不共享线路，价格差得也不小。

### 4. 计费周期，算的是年到手价

月付价好看，年付价才接近真实成本。行业里常见的折扣梯度是季付 9 折、半年付 8 折、年付 7 折。算的时候别只看标价，把折扣叠进去再对比。

### 5. 退款和试用政策，比参数更能说明厂商心态

能 7 天无理由退款的，和“一经售出不退”的，试用成本完全不是一回事。前者你敢试一个月，后者你只能赌。

## 五、几个高频问题

**Q：1 元试用靠谱吗？**
云服务器和游戏云支持 1 元试用 1 天，每款限 1 次。高配机型试用价会更高（部分要 20~30 元）。想验证线路和延迟，这是成本最低的方式，比看任何评测都准。

**Q：硬盘能扩容吗？**
能。云盘支持弹性增减，高速固态约 0.4 元/GB/月，高效云盘约 0.1 元/GB/月，按需加。

**Q：可以降配或者换机房吗？**
购买后可以按天补差价升级套餐，也支持扩容云盘、加购独立 IP。降配和迁移的具体规则，下单前在控制台或工单里确认一遍更稳妥。

**Q：退款规则是什么？**
7 天内无理由退款，每个账号限 3 次。这条对第一次租 VPS 的人价值很高——不确定能不能跑起来，先买一个月，不合适就退。

**Q：需要备案吗？**
海外节点（香港、美国、日本、韩国、德国）免备案。国内节点如果只是跑跑程序、数据库不需要备案，用域名对外提供网站服务则需要。
